IRIS ENERGY WEBSITE PACKAGE
===========================

Purpose
-------
This package contains the content and image assets required to begin building the IRIS Energy website.

Privacy and publishing rule
---------------------------
All source phone numbers, email addresses, physical addresses and legacy website links have been omitted. Do not copy contact details from the original source documents into the website. The enquiry form's private routing destination must be configured separately by the site owner.

Folder structure
----------------
01_Content
  - IRIS_Energy_Website_Content_No_Contacts.docx
  - IRIS_Energy_Website_Copy_No_Contacts.md

02_Web_Ready_Photos
  - Homepage
  - Products
  - Projects
  - Installation
  - Technical

03_Pending_Approval
  - Photographs showing people or requiring consent
  - Low-resolution controller photograph

Important
---------
The Word guide contains a confirmation checklist. Conflicting capacity figures, installation counts, legal relationship wording, marketing claims, model data and customer references must be approved before publication.

Image processing
----------------
Website-ready images have been renamed, converted to WebP, resized only when necessary and stripped of embedded metadata. Original source photographs remain outside this handoff package.
